openclaw 개인정보처리방침

시행일: 2026-11-08 · Polar.ai

1. 대상

openclaw는 Polar.ai가 내부 업무에만 쓰는 도구입니다. 연결되는 Google 계정은 Polar.ai 담당자 본인의 계정뿐이며, 외부 사용자의 정보를 수집하지 않습니다.

2. 접근하는 Google 데이터와 용도

  • Gmail: 받은 메일 확인·요약, 담당자가 요청한 메일 작성·발송
  • Google 캘린더: 일정 확인과 담당자가 요청한 일정 등록·수정
  • Google Drive, Docs, Sheets, Slides: 담당자가 요청한 문서 조회·작성·수정

이 데이터는 담당자가 요청한 업무를 처리하는 데에만 쓰며, 광고, 판매, 프로파일링에 쓰지 않습니다.

3. 보관과 공유

Google 접근 토큰은 회사가 관리하는 서버에만 저장합니다. 업무 처리를 위해 내용 일부가 언어 모델 API로 전달될 수 있으며, 그 밖의 제3자에게 판매하거나 공유하지 않습니다. 업무 기록은 회사 내부 시스템에만 남습니다.

4. Google API 서비스 사용자 데이터 정책 준수

openclaw가 Google API로 받은 정보의 사용과 다른 앱으로의 전송은 제한적 사용 요건을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

5. 접근 철회

연결된 계정 소유자는 언제든 Google 계정의 서드파티 액세스에서 openclaw의 접근을 철회할 수 있습니다.

English summary

openclaw is an internal Polar.ai tool. It connects only the operator's own Google account and uses Gmail, Calendar, Drive, Docs, Sheets and Slides data solely to carry out tasks the operator asks for. Tokens are stored on company-managed servers; data is not sold, used for advertising, or shared with third parties beyond the language-model API used to process a request. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions.
